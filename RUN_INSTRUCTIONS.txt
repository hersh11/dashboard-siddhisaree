How to Run the Siddhi Sarees Dashboard Locally

1. Open PowerShell.

2. Go to the dashboard folder:

   cd path\to\dashboard-siddhisaree   (the folder that contains server.js)

3. Start the local server:

   node server.js

4. Open this link in your browser:

   http://127.0.0.1:8766/index.html

5. Keep the PowerShell window open while using the dashboard.

6. To stop the server, go back to PowerShell and press:

   Ctrl + C

Notes:

- The dashboard runs locally on your computer.
- Internet is not required: Chart.js and the fonts are saved in the project folder.
- The dashboard data is loaded from dashboard-data.js, which was generated from the Excel workbook.
- If port 8766 is already in use, close the old server window or change the port in server.js.
